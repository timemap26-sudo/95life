# 95life — 95分人生

一款人生模擬小遊戲。從 6 歲活到 80 歲，在 26 個人生關卡做選擇（當憲兵、澳洲留學、三次換工作、在朋友家遇到陳羿名、退休買房、買魚池養魚…），中間還會遇到「人生意外」—— 每件事都可以自己選擇怎麼面對。

- 五項數值：💪健康　💰財富　❤️感情　😊快樂　📚智慧
- 畫面右上角隨時顯示**人生總分**，每個選擇後即時更新（總分 = 平均 × 60% ＋ 最弱項 × 40%）
- 主角用插畫頭像，**表情會隨遭遇改變**（大笑、開心、平靜、得意、難過、大哭、驚嚇、生氣），並且**隨年紀變老**：小時候戴小黃帽、當兵戴憲兵鋼盔、中年長皺紋、頭髮慢慢變白、戴上老花眼鏡
- 每個事件都有一張**情境插圖**，每個選項也都有自己的**插圖卡片**
- 活到 80 歲後畫出你的**人生地圖**：走過的每一站、當時的選擇、總分走勢，點一下可以回顧細節，也能下載成圖片
- 目標：**95 分人生**

## 怎麼玩

用瀏覽器打開 `index.html`，不需要安裝任何東西（`assets/` 資料夾要跟著放在一起）。
